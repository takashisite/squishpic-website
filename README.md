# SquishPic Website

Official website for [SquishPic](https://squishpic.app) - a fast image compression app for macOS.

## Structure

```
squishpic-website/
├── index.html          # English (default)
├── privacy.html        # Privacy Policy (English)
├── ja/
│   ├── index.html      # Japanese
│   └── privacy.html    # Privacy Policy (Japanese)
├── css/
│   └── style.css       # Shared styles
└── images/
    ├── icon.png        # App icon
    ├── screenshot1.png # App screenshot
    └── appstore.svg    # App Store badge
```

## Deployment

This site is deployed on [Cloudflare Pages](https://pages.cloudflare.com/).
